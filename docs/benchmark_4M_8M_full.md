## 结论

1. **RDMA 优化后全面优于 GDS**（4MB 所有并发，8MB 真实写入）
2. **Pre-build header 是关键优化** — 卸载 event loop + 自然的流水线节流
3. **GDS 瓶颈**: event loop 处理（单线程 cuObj 回调），32 线程时接近平台
4. **8MB no-disk 异常**: RDMA 在 conc≥16 后吞吐下降，疑似 NIC 竞争或 event loop 拥塞
5. **磁盘写入对 GDS 影响更大**: GDS 8MB w-disk 仅 44% no-disk 性能，RDMA 保持 89-117%
