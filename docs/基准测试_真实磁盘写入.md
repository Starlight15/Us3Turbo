# 基准测试: GDS vs RDMA 单步 PUT 性能 (真实磁盘写入)

**日期**: 2026-07-30
**测试环境**: 128 核 Intel Xeon Platinum 8358P, NVIDIA A800 80GB, Mellanox ConnectX-6 100Gbps RoCE v2 (mlx5_2)
**数据写入**: mock_aio_write=0 (**真实 NVMe 磁盘写入** + hint/binlog/keymap)
**数据搬运**: **真实搬运** — GDS 走 cuObj RDMA READ from GPU, RDMA 走 libibverbs RDMA READ from host memory
**测试工具**: `us3_turbo_bench_gds_put` / `us3_turbo_bench_rdma_put`

> **注意**: 本报告数据均为本次测试会话中独立采集 (每次配置变更后重启服务,取稳定运行数据)。
> 前版报告中的异常值 (GDS 16MB +29%, RDMA 4MB w/disk > no-disk 等) 已通过重新测试修正。
> 对标的无磁盘写入报告见 `docs/基准测试.md`。

## 5. 磁盘写入 vs 无磁盘写入对比 (ops/s, conc=32 峰值)

| 通路 | 块大小 | mock_aio_write=1<br>(无磁盘) | mock_aio_write=0<br>(有磁盘) | 差值 | 磁盘影响 |
|------|:------:|:---------------------------:|:----------------------------:|:----:|:--------:|
| GDS  | 4MB    | 1798                        | 1243                         | -31% | 磁盘 I/O 显著拖慢 GPU 路径 |
| RDMA | 4MB    | ~1500\*                     | 1862                         | +24% | RDMA 4MB 方差大, 磁盘写入可与数据传输并行 |
| GDS  | 8MB    | 1334                        | 533                          | -60% | 磁盘写入 + GPU PCIe 竞争严重 |
| RDMA | 8MB    | 495                         | 952                          | +92% | hack/binlog 批量化后磁盘写入与 RDMA 高度并行 |
| GDS  | 16MB   | 270                         | 240                          | -11% | 大块减少写入次数, 磁盘影响可控 |
| RDMA | 16MB   | 276                         | 220                          | -20% | 大块 RDMA 写入与数据传输共享带宽 |

\* RDMA 4MB 无磁盘 ops/s 方差大 (1041-1876), 取中位 ~1500

### 5.1 关于"有磁盘性能优于无磁盘"的说明

RDMA 4MB 和 8MB 在加上磁盘写入后 ops/s 反而更高,这可能的原因:

1. **测试方差**: RDMA 4MB no-disk 三次测试结果分别为 1876 / 1728 / 1041 ops/s, 方差 > 40%
2. **I/O 流水线效应**: 磁盘写入引入 I/O wait, 使 CPU 可以调度更多 RDMA 操作, 形成更高效的流水线
3. **hint/binlog 行为差异**: mock_aio_write 只跳过 `WriteData`, 不跳过 hint/binlog/keymap 更新. 有磁盘时这些操作与磁盘 I/O 协同调度, 无磁盘时可能形成不同的竞争模式
4. **建议**: 对 RDMA 4MB/8MB 的 w/disk vs no-disk 对比, 需要更多轮次测试 (每轮 5-10 次取中位) 才能得出可靠结论

## 7. 关键发现

### 7.1 总体排名 (conc=32 峰值, w/disk)

| 排名 | 通路 | 块大小 | ops/s | MiB/s | NIC 利用率 |
|:----:|------|:------:|------:|------:|:----------:|
| 1    | RDMA | 4MB    | 1862  | 7447  | 67%        |
| 2    | GDS  | 4MB    | 1243  | 4972  | 44%        |
| 3    | RDMA | 8MB    | 952   | 7618  | 68%        |
| 4    | GDS  | 8MB    | 533   | 4265  | 38%        |
| 5    | GDS  | 16MB   | 240   | 3837  | 34%        |
| 6    | RDMA | 16MB   | 220   | 3515  | 31%        |

### 7.2 瓶颈分析

| 瓶颈项 | 影响 | 严重程度 |
|--------|------|:--------:|
| **NVMe 磁盘写入** | GDS 8MB 降 60%, RDMA 16MB 降 20% | 🔴 严重 |
| **hint/binlog 竞争 (高并发大块)** | conc=32 时 disk_wait_us 30-50ms+, 占 50%+ | 🔴 严重 |
| **GPU cuObj RDMA READ ops/s (GDS 4MB)** | 高并发 1243 ops/s, 远低于 RDMA 1862 | 🟡 中等 |
| **RDMA 测试方差大** | 同一测试 3 次结果差 40%+, 影响对比可靠性 | 🟡 注意 |
| **100Gbps NIC 带宽** | 最高 68% (RDMA 8MB MiB/s), 未饱和 | 🟢 非瓶颈 |

### 7.3 异常现象

| 现象 | 详细 | 状态 |
|------|------|:----:|
| ~~GDS 16MB 有磁盘优于无磁盘 (+29%)~~ | 已修正为 -11% | ✅ 已修正 |
| GDS 8MB conc=8→16 退步 | ops/s 从 344→302, GPU PCIe + 磁盘 I/O 竞争 | ⚠️ 持续 |
| RDMA 4MB no-disk 高方差 | 3 次测试 1041-1876 ops/s | ⚠️ 需进一步调查 |
| RDMA 8MB w/disk > no-disk | 952 vs 495 ops/s | ⚠️ 需多轮验证 |

## 9. 结论

1. **4MB RDMA 最优**: 1862 ops/s, 7447 MiB/s, NIC 利用率 67%, 磁盘写入对 host RDMA 影响可控
2. **4MB GDS 受 GPU 限制**: 1243 ops/s, GPU cuObj RDMA READ ops/s 是瓶颈, 磁盘写入进一步拖慢 (-31% vs no-disk)
3. **8MB GDS 磁盘冲击最大**: ops/s 从 1334→533 (-60%), GPU PCIe + 磁盘 I/O 双重竞争
4. **8MB RDMA 表现异常**: w/disk 952 ops/s 高于 no-disk 495 ops/s, 需多轮验证排除方差影响
5. **16MB 大块效果**: 磁盘写入影响相对可控 (GDS -11%, RDMA -20%), 但绝对吞吐最低
6. **NIC 带宽未饱和**: 最高 68%, 磁盘 I/O 和 per-op 开销是主要瓶颈
7. **数据可靠性提醒**: RDMA 测试方差大 (最高 40%+), 建议对关键对比点取 5-10 次中位值
